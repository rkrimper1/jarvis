# Jarvis iOS Client

Swift/SwiftUI voice client for the Jarvis backend.

## Location in monorepo

```
jarvis/
├── clients/
│   └── ios/
│       └── JarvisClient/       ← Xcode project + SPM manifest
│           ├── Package.swift
│           ├── JarvisClient/
│           │   ├── App/            JarvisApp.swift
│           │   ├── Proto/          ← symlink → ../../../../gen/swift/
│           │   ├── Services/       GRPCVoiceService.swift
│           │   │                   AudioCaptureEngine.swift
│           │   │                   WakeWordDetector.swift
│           │   ├── ViewModels/     VoiceViewModel.swift
│           │   └── Views/          HUDView.swift
│           │                       WaveformView.swift
│           │                       TranscriptView.swift
│           └── JarvisClientTests/
├── gen/
│   ├── go/                     ← generated Go stubs
│   └── swift/                  ← generated Swift stubs (buf generate)
└── proto/
    └── voice/voice.proto       ← source of truth
```

## Prerequisites

- Xcode 15+
- iOS 17+ deployment target
- `buf` CLI (`brew install bufbuild/buf/buf`)

## Getting started

```bash
# From the repo root — generates both Go and Swift stubs
make proto

# Open in Xcode
open clients/ios/JarvisClient/JarvisClient.xcodeproj
```

## Proto → Swift codegen

Swift stubs are generated by `buf generate` using the `buf.build/apple/swift`
and `buf.build/grpc/swift` plugins defined in `buf.gen.yaml` at the repo root.
Output lands in `gen/swift/` which the `JarvisProto` SPM target references.

Run `make proto` any time `proto/voice/voice.proto` changes.

## Configuration

Edit `VoiceServiceConfiguration` in `GRPCVoiceService.swift`:

| Preset | Host | Port | TLS |
|---|---|---|---|
| `.development` | `localhost` | `50059` | No |
| `.production`  | `voice.jarvis.yourdomain.com` | `443` | Yes |

Point `.development` at your local `docker compose up` stack.
